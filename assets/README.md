# Image assets

Add your PNG files using these exact names:

| File | Used on |
| --- | --- |
| `renewal-logo.png` | Welcome and role-selection screens |
| `renewal-logo-white.png` | Purple Google sign-in screen |
| `renewal-church-home.png` | Welcome-screen church photo |
| `parking-lot-map.png` | Parking-lot map screen |
| `settings-floral-decoration.png` | Settings-screen decoration |

Every image area shows its expected filename when the PNG is missing, so you can replace the assets without changing JavaScript or CSS.
